Spreadsheet Link Types

Distinguish the four navigation roles: spreadsheet, row reference, category route, and next destination.

Four roles on one path

A link is not just a link. Each link on the way to a destination plays one of four roles. Recognize the role so you know what the link can and cannot tell you.

Spreadsheet

This role organizes the public entry and the overall browsing scope. It is the starting map, not a promise about any single listing.

Row reference

This role provides only one row's local clue and context. It points at a single row and nothing beyond it.

Category route

This role helps narrow the browsing category. It is a wayfinding step, not a product page.

Next destination

This role shows the information actually visible on the current page. It is where you finally read the live details.

What the roles do not mean

These roles describe navigation purpose only. They do not signal credibility, quality, or real-time status, and you cannot assume they are all maintained by the same party.

Bank noteThe border or position of a link marks its role. It never marks the link as safe, verified, live, or working.
!Open item: has a link's role been read as a trustworthiness signal, instead of a navigation purpose?

A worked path

  1. Spreadsheet: the shared document opens the scope.
  2. Row reference: one row names a bag.
  3. Category route: the Bags category narrows the view.
  4. Next destination: the product page shows what is visible now.
